# Run: fix "Internal Server Error" on the preview app

- **Goal**: user reported only "Internal Server Error" on the running app; get it serving.
- **Specs**: none (operational fix).
- **Root cause**: the sandbox preview server (port 3000, started 09:33) was a stale `next dev` process with cwd `/workspace`, launched before the monorepo restructure. The app now lives in `packages/app`, so it failed with `ENOENT: scandir '/workspace/src/app'` and `Cannot find module 'next/dist/pages/_error'` (see `/workspace/.next/dev/logs/next-development.log`).
- **Fix**: `fuser -k 3000/tcp`. The sandbox supervisor respawned it via `openmercato.toml` → `npm run dev -- …` → `npm run dev -w @devmentor/app`, cwd `packages/app`. No code changes.
- **Verified**: `GET /` 200, `GET /backend` 200, `GET /api/users` 200 (`{"ok":true,"data":{"items":[],…}}`).
- **Open issue**: no `devmentor` database exists on the sandbox Postgres; the server inherits the shell `DATABASE_URL` (`open-mercato` DB), so `/api/users` reads that foreign DB (which has a `users` table from the earlier incident, see monorepo-bootstrap run). Needs a user decision: create a dedicated `devmentor` DB and point the preview at it.
- **Stale artefact**: `/workspace/.next` (root) is left over from the old layout; safe to delete.
