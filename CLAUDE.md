# Claude Code specifics

The `.ai/` metadata structure documented in `AGENTS.md` is mandatory for Claude Code too. In particular:

- Read `.ai/lessons.md` before starting work; record new lessons there (details in `.ai/lessons/`) after fixing bugs or learning something durable.
- Follow and keep up to date the specs in `.ai/specs/` (`implemented/` when done, `archive/` when obsolete).
- Write a log for every autonomous run to `.ai/runs/YYYY-MM-DD-slug.md`.
- All files in `specs/`, `runs/` and `lessons/` use the `YYYY-MM-DD-slug.md` naming.
